## Architectural boundary

Reusable runtime systems must not import the original game's economy, multiplayer service, local-storage keys or source asset URLs. An explicit Arkodia content adapter consumes supported versioned published documents and resolves binary paths only through verified digest bindings. The Content API continues ordinary asset upload, draft Save/reload and immutable publication; consumer document/asset hashes and byte-size checks remain mandatory. Runtime deployment replaces only its dedicated service, preserving Content API and original game deployments.
